PersonaDao

interface PersonaDao

DAO encargado de las operaciones de acceso a datos relacionadas con personas.

Gestiona tanto la entidad base PersonaEntity como sus especializaciones UsuarioEntity (alumno) y ProfesorEntity, siguiendo un modelo de herencia simulada mediante tablas relacionadas.

Incluye operaciones de:

  • Autenticación (login)

  • Inserción de personas y sus subtipos

  • Recuperación de datos específicos según el rol
