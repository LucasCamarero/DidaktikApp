ActivityData

data class ActivityData(val id: Int, val title: String, val description: String, @DrawableRes val imageResId: Int, val imageDescription: String, val gameRoute: String)

Modelo de datos que representa una actividad principal (juego) de la aplicación.

Cada instancia encapsula toda la información necesaria para mostrar una actividad en la interfaz de usuario y para navegar hacia su juego o pantalla asociada.
