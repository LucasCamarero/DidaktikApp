createNumberedMarker

fun createNumberedMarker(context: Context, number: Int, backgroundColor: Int = 0xFFF5DC21.toInt(), textColor: Int = 0xFF000000.toInt()): Bitmap

Crea un marcador circular numerado como Bitmap.

Este marcador está pensado para su uso en mapas basados en APIs Android clásicas (por ejemplo, OSMDroid), donde se requiere un Bitmap o Drawable como icono del marcador.

El marcador consiste en:

  • Un fondo circular de color configurable.

  • Un número centrado que representa el identificador de la actividad.

Los colores se reciben como enteros ARGB (Int), lo que permite integrarlo fácilmente con colores provenientes de Compose mediante toArgb().

Return

Un Bitmap que representa el marcador numerado.

Parameters

context

Contexto de Android necesario para la creación de recursos gráficos.

number

Número que se mostrará en el centro del marcador.

backgroundColor

Color de fondo del marcador en formato ARGB. Por defecto, amarillo.

textColor

Color del texto del número en formato ARGB. Por defecto, negro.
