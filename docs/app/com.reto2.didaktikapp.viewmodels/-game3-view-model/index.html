Game3ViewModel

class Game3ViewModel @Inject constructor(progresoDao: ProgresoDao) : ViewModel

ViewModel que gestiona la lógica del juego de sopa de letras correspondiente a la Actividad 3.

Controla:

  • El grid de letras

  • Las palabras objetivo

  • La selección del usuario

  • La detección de palabras encontradas

  • El estado de finalización del juego

  • La persistencia del progreso en base de datos
