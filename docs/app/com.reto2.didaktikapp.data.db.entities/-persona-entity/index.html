PersonaEntity

data class PersonaEntity(val persona_id: Int = 0, val username: String, val password_hash: String, val tipo_persona: String)

Entidad de base de datos que representa a una persona registrada en la aplicación.

Esta entidad se almacena en la tabla persona y es utilizada por Room como modelo persistente. Puede representar distintos tipos de usuarios, como alumnado o profesorado, en función del valor del campo tipo_persona.
