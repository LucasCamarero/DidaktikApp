UsuarioEntity

data class UsuarioEntity(val persona_fk: Int, val nombre_completo_diploma: String)

Entidad de base de datos que representa a un usuario (alumno) dentro de la aplicación.

Esta entidad está asociada de forma directa a PersonaEntity mediante una relación uno a uno (1:1). Comparte el mismo identificador como clave primaria y clave foránea, garantizando que cada usuario corresponde exactamente a una persona.
