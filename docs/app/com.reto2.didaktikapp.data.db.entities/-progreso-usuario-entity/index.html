ProgresoUsuarioEntity

data class ProgresoUsuarioEntity(val progreso_id: Int = 0, val actividad_fk: Int, val persona_fk: Int, val completada: Int, val fecha_completado: String?)

Entidad de base de datos que representa el progreso de un usuario en una actividad.

Esta entidad actúa como una tabla de relación entre personas (alumnos) y actividades, almacenando el estado de finalización y la fecha asociada.
